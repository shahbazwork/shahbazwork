## ⌁ Engineering Standards

- **Architecture before code.** Every system is designed for change before a single line is written.
- **Documentation is a deliverable.** Onboarding a new developer should take hours, not weeks.
- **Proactive communication.** Status, blockers, decisions — always in writing, never assumed.
- **Built for handoff.** Every engagement ends with code another team can confidently own.
- **Outcomes over output.** Performance, reliability, and business impact — not line count.
